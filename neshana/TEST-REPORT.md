خروجی ماشینی بررسی نقشه در `verification/live-map.json` قرار دارد. این آزمون از کد بخش‌های نقشه و PNG در خروجی نهایی استفاده می‌کند. ذخیرهٔ این نمونهٔ آزمون با دادهٔ OpenMapTiles، آزمون دانلود کامل آرشیو PMTiles روی گوشی محسوب نمی‌شود.

## منشأ خطای گزارش‌شده

در ZIP ورودی، کتابخانه‌های نقشه از قبل bundle بودند و هر ۹۰ تست موجود نیز موفق بود. خطای `@mapbox/point-geometry` در همان فایل‌های ورودی تکرار نشد؛ چنین خطایی با دریافت فایل ESM خامِ npm از نسخهٔ قدیمی یا ترکیب نسخه‌های کش‌شده سازگار است. نشانی سرویس منتشرشده و کش دستگاه کاربر در اختیار این بررسی نبود، بنابراین منشأ دقیق نسخهٔ اجراشده قطعی نیست.

اصلاحیه خروجی اصلی و بخش‌های وابسته را bundle و نام‌گذاری مبتنی بر محتوا می‌کند؛ از پذیرش فایل‌های ناسازگار در به‌روزرسانی جلوگیری می‌کند و خطای راه‌اندازی نقشه را از کارکرد اصلی جدا نگه می‌دارد.

## محدودیت‌ها

Chromium پیش از بازکردن صفحه در محیط اجرا متوقف شد؛ WebKit وابستگی‌های سیستمی لازم را نداشت. تست موفق واقعی مرورگر، Android/iOS، Safari، Add to Home Screen، GPS، دوربین، Web Share، VoiceOver و چیدمان صفحه روی دستگاه فیزیکی ادعا نمی‌شود. تست‌های DOM و Service Worker شبیه‌سازی‌شده‌اند؛ رندر تصاویر از Canvas واقعیِ Node استفاده می‌کند.

تست شبکه فقط دسترسی همین محیط به سرویس نقشه را نشان می‌دهد. محدودیت شبکه یا دسترسی به سرویس‌های خارجی در دستگاه کاربر باید جداگانه بررسی شود.

## تکرار بررسی

```sh
npm ci
npm run verify
npm run check:map
npm run serve
```

`check:map` اینترنت می‌خواهد و تصاویر آزمایشی و نتیجه را در `.test-output` می‌نویسد. نسخهٔ آمادهٔ انتشار همراه این ZIP در `dist` قرار دارد.
