# راه‌اندازی نشانا ۳٫۲٫۲

۱. تمام فایل‌ها و پوشه‌های داخل `dist` را روی همان دامنه و همان مسیر نسخهٔ قبلی قرار دهید. محتویات پوشه باید کنار هم باشند؛ فایل‌های `app-…` و `chunk-…` هم ضروری‌اند. نسخه آماده است و روی میزبان به npm یا build نیاز ندارد.

۲. سایت را با HTTPS باز کنید. بازکردن `index.html` با دوبارکلیک یا `file://` برای اجرای این PWA مناسب نیست. میزبان باید فایل‌های `.mjs` و `.js` را با نوع JavaScript پاسخ دهد. فایل `_headers` برای میزبان‌هایی است که آن را پشتیبانی می‌کنند؛ در سایر میزبان‌ها معادل آن را در تنظیمات سرور اعمال کنید.

۳. برای نسخهٔ قبلی که گیر کرده است، پس از انتشار کامل این نشانی را باز کنید:

`https://YOUR-DOMAIN/YOUR-APP-PATH/repair.html?v=3.2.2`

بخش دامنه و مسیر را با نشانی فعلی برنامه عوض کنید. صفحهٔ بازیابی منتظر دریافت کامل اصلاحیه می‌ماند و سپس برنامه را باز می‌کند. اگر دریافت شکست خورد، اتصال و کامل‌بودن فایل‌های منتشرشده را بررسی کنید و «تلاش دوباره» را بزنید.

۴. نسخهٔ Home Screen را با اینترنت ببندید و دوباره باز کنید؛ اگر گزینهٔ به‌روزرسانی نمایش داده شد، ابتدا فرم باز را ذخیره کنید و آن را بزنید. اگر پیوند «به‌روزرسانی و باز کردن نشانا» ظاهر شد، از همان پیوند داخل برنامه استفاده کنید. فضای دادهٔ Safari و Home Screen ممکن است جدا باشد؛ بازیابی در Safari به‌تنهایی تضمین نمی‌کند فضای جداگانهٔ نسخهٔ نصب‌شده هم تازه شود. برنامه را حذف و داده‌های سایت را پاک نکنید. برای انتقال اطلاعات بین فضاها از پشتیبان استفاده کنید.

۵. پس از بازشدن، در تنظیمات «بررسی آمادگی آفلاین» را اجرا کنید. برای دیدن نقشه بدون اینترنت، محدودهٔ موردنظر را از تنظیمات نقشه دانلود کنید؛ ذخیرهٔ خود برنامه به‌تنهایی به معنی دانلود نقشه نیست.

## اجرای محلی برای توسعه

Node.js 22 یا جدیدتر:

```sh
npm ci
npm run verify
npm run serve
```

نشانی چاپ‌شده را روی همان کامپیوتر باز کنید. HTTP روی localhost برای بررسی PWA مجاز است؛ برای گوشی از میزبان HTTPS استفاده کنید.

پس از ویرایش فایل‌ها دوباره `npm run verify` را اجرا کنید. فایل‌ها پس از build نباید در سرور بازنویسی یا minify شوند؛ اگر میزبان این کار را انجام دهد، بررسی SHA-256 دریافت آن نسخه را رد می‌کند. فایل‌های نسخهٔ جدید را ابتدا کامل بارگذاری کنید و سپس `index.html`، `repair.html`، `repair.js` و `sw.js` را جایگزین کنید. انتشار اتمی پوشه بهترین روش است.
