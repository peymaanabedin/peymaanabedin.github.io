# Save Loc 2.0

اپلیکیشن فارسی/انگلیسی برای ثبت، دسته‌بندی، اشتراک و پیدا کردن دوبارهٔ مکان‌ها. رابط موبایل‌فرست با فونت Peyda پیوست‌شده، حالت روشن/تیره، نقشه، فرم‌های پایین صفحه و آیکون اختصاصی ترکیبی «پین + نشانک».

## اجرا و انتشار

تمام محتوای پوشهٔ `dist` را روی یک میزبان HTTPS قرار دهید. هیچ مرحلهٔ build یا backend لازم نیست. فایل `index.html` به‌تنهایی PWA نیست؛ فونت‌ها، آیکون‌ها، manifest و `sw.js` باید کنار آن منتشر شوند. مسیر نسبی فایل‌ها از انتشار در زیرپوشه نیز پشتیبانی می‌کند. تنظیمات میزبانی Sites در `.openai/hosting.json` است.

```sh
npm ci
npm test
npm run check
```

بستهٔ `linkedom` فقط برای آزمون DOM است و در برنامهٔ منتشرشده استفاده نمی‌شود. تنها کتابخانهٔ زمان اجرا Leaflet 1.9.4 است که همراه مجوز آن به‌صورت محلی نگهداری می‌شود. اسکریپت Tailwind، آیکون‌های CDN و فونت خارجی حذف شده‌اند.

## نصب روی آیفون

1. آدرس HTTPS برنامه را در Safari باز کنید؛ در میزبانی خصوصی در صورت درخواست وارد حساب مجاز شوید.
2. Share را بزنید و Add to Home Screen را انتخاب کنید.
3. اگر Open as Web App وجود دارد، روشن باشد؛ Add را بزنید.
4. یک‌بار برنامه را با اینترنت باز کنید تا فایل‌های پایه برای آفلاین آماده شوند.
5. برای انتقال مکان‌های نسخهٔ قدیمی، در همان نسخه خروجی JSON یا پشتیبان بگیرید؛ در این نسخه از «تنظیمات ← ورود فایل یا بازیابی» استفاده کنید.

هدف سازگاری iOS / iPadOS 16.4 به بعد و مرورگرهای جدید است. نصب واقعی، GPS واقعی، ظاهر در Safari، مدیریت صفحه‌کلید و VoiceOver در این محیط آزمایش نشده‌اند؛ آزمون‌های DOM جایگزین آزمون دستگاه نیستند.

## داده و سازگاری نسخهٔ قبلی

داده‌ها فقط در localStorage مرورگر و با کلید `saveloc.state.v2` ذخیره می‌شوند. هر تغییر شامل مکان‌ها، دسته‌ها و تنظیمات، با یک write انجام می‌شود. خطای quota یا دسترسی به حافظه به کاربر اعلام می‌شود و موفقیت کاذب نمایش داده نمی‌شود.

کلیدهای `saveloc.places.v1`، `saveloc.categories.v1`، `saveloc.prefs.v1` و ترجیحات قبلی در همان origin خوانده می‌شوند؛ اصل آن‌ها بازنویسی نمی‌شود. داده‌های origin دیگر یا نسخهٔ نصب‌شدهٔ iOS ممکن است جدا باشند و به انتقال JSON نیاز دارند.

ورود فایل آرایهٔ قدیمی، پشتیبان نسخهٔ ۱ و پشتیبان نسخهٔ ۲ پشتیبانی می‌شود. محدودیت: ۵ مگابایت، ۵۰۰۰ مکان، ۱۰۰ دسته. مختصات خالی، غیرعددی یا خارج از بازه و شناسه‌های تکراری داخل فایل رد می‌شوند. ادغام، مکان‌های قبلی با شناسهٔ مشترک را حفظ می‌کند. بازیابی کامل فقط پس از تأیید جداگانه داده‌ها را جایگزین می‌کند. حذف مکان دارای واگرد موقت است؛ حذف دسته، مکان‌ها را به «سایر» منتقل می‌کند.

## آفلاین و سرویس‌های بیرونی

Service Worker واقعی با URL هم‌مبدأ فایل‌های پایه، کد، فونت و آیکون را cache می‌کند. فهرست، ویرایش، حذف، ورود مختصات و پشتیبان آفلاین کار می‌کنند. نقشه و جستجوی آدرس به اینترنت نیاز دارند. tiles یا APIهای بیرونی cache یا پیش‌بارگیری انبوه نمی‌شوند. ارتقای نسخه پس از تأیید کاربر انجام می‌شود و فرم باز، به‌روزرسانی را متوقف می‌کند. هنگام تغییر فایل‌های برنامه، مقدار `CACHE` در `dist/sw.js` را تغییر دهید.

نقشه: CARTO با داده‌های OpenStreetMap و attribution نمایان. جستجو و آدرس: Photon / Komoot، فقط پس از اقدام کاربر، با cache محدود، صف درخواست، حداقل فاصلهٔ ۱٫۱ ثانیه و timeout. آدرس endpoint در `dist/services.json` قابل تغییر است. سرویس عمومی Photon ضمانت دسترسی ندارد؛ برای ترافیک گسترده از سرویس اختصاصی یا میزبانی Photon خودتان استفاده کنید. رابط در قطع سرویس همچنان اجازهٔ ذخیرهٔ مختصات می‌دهد.

مسیریابی: لینک HTTPS اپل، گوگل و Waze. برای اسنپ و تپسی، کپی مختصات و لینک وب‌اپ مستقل ارائه شده است؛ پارامتر مقصد تأییدنشده یا scheme حدسی استفاده نمی‌شود. لینک سفارشی با scheme امن، جای‌گذاری و URL encoding پشتیبانی می‌شود.

موقعیت با watch حداکثر ۱۸ ثانیه دریافت می‌شود. اولین نتیجه فوراً قابل استفاده است؛ نتیجهٔ دقیق‌تر جایگزین می‌شود و در دقت گزارش‌شدهٔ ۲۰ متر یا پایان مهلت watch بسته می‌شود. مخفی‌شدن صفحه، انتخاب دستی یا بازشدن فرم ثبت، watch را متوقف می‌کند. ارتفاع از دستگاه دریافت می‌شود و دریافت موقعیت به API ارتفاع وابسته نیست. دقت GPS تضمین نمی‌شود و نقطهٔ دستی دقت صفر جعلی ندارد.

## آزمون و حدود بررسی

۴۰ آزمون در زمان تحویل موفق بودند: مهاجرت داده، ورودی خراب، شناسه‌ها، ادغام، خطای حافظه، دسته‌بندی، نرمال‌سازی فارسی، لینک‌های امن، مسابقهٔ پاسخ‌های GPS، timeout و لغو، ذخیره/ویرایش/حذف/واگرد در DOM، ترجمه/تم، مراحل نصب و قراردادهای Service Worker و آیکون‌ها. درخواست‌های واقعی خواندنی برای Photon، tiles و وب‌اپ‌های تاکسی موفق بودند؛ پاسخ Photon با هدر Origin دارای CORS مجاز بود.

ابزار رسمی کنترل مرورگر در این محیط در دسترس نبود؛ آزمون تصویری/مرورگری، نصب در Safari، cache واقعی مرورگر، GPS واقعی، popup/Web Share و کارایی روی آیفون واقعی تأیید نشده‌اند. هیچ دادهٔ ساختگی به فهرست کاربر اضافه نشده و نمای اولیهٔ تهران به‌عنوان موقعیت فعلی معرفی نمی‌شود.

راهنمای پذیرش روی دستگاه: نمایش در عرض‌های ۳۲۰، ۳۷۵، ۳۹۰ و ۴۳۰؛ پرتره/لندسکیپ؛ صفحه‌کلید در فرم یادداشت؛ safe area؛ افزایش اندازهٔ متن؛ VoiceOver و فوکوس؛ رد/اعطای GPS؛ عدم اتصال؛ بازکردن اپ از Home Screen؛ دانلود/ورود پشتیبان؛ اشتراک و بازکردن مسیریاب. این موارد چک‌لیست باقی‌مانده‌اند، نه ادعای تست موفق.
